Dia · Teoría y ejercitación

Dia es un programa libre y gratuito para armar diagramas. Acá aprendés a instalarlo, a dibujar el MER con la hoja ER, a dibujar el DER con la hoja Database y a guardar y exportar el trabajo. Cada tema tiene su pestaña ✍️ Ejercitación.

1 Qué es Dia y cómo se usa la pantalla

Dia es un editor de diagramas libre (una alternativa a Visio). Se usa para pasar el MER y el DER del papel a la computadora. No genera la base de datos: sirve para dibujar y exportar el diagrama.

Instalación
SistemaCómo se instala
WindowsBajar el instalador desde dia-installer.de (sección Download) y ejecutarlo.
Linuxsudo apt install dia
MacInstalar con Homebrew o desde el sitio oficial.
Las tres zonas de la pantalla
Lienzo central
La hoja blanca donde se arma el diagrama. Se hace zoom con Ctrl + rueda del mouse.
Paleta izquierda
Las figuras disponibles. Arriba hay un desplegable que cambia de hoja: ER, Database, Flowchart, etc.
Barra de herramientas
Arriba del lienzo: guardar, deshacer, zoom, texto, líneas y colores.
El gesto básico: elegir y colocar
  1. Elegí la hoja en el desplegable de la paleta (por ejemplo, ER).
  2. Hacé clic en una figura de la paleta.
  3. Hacé clic en el lienzo para colocarla.
  4. Hacé doble clic sobre la figura para escribir su nombre.
  5. Arrastrá desde los bordes para conectarla con otra figura.
Truco: si una figura no aparece, revisá la hoja seleccionada. La hoja ER tiene las figuras del MER; la hoja Database tiene las tablas del DER. No están mezcladas.
Error clásico: dibujar todo en una hoja cualquiera sin mirar el desplegable. Si no encontrás Entity, Relationship o Table, es porque estás en la hoja equivocada.

2 La hoja ER: dibujar el MER

En el desplegable de la paleta se elige la hoja ER. Ahí están las figuras del modelo conceptual: Entity, Relationship y Attribute. Con esas tres alcanza para dibujar el MER completo.

Qué querés dibujarHoja y figura en DiaForma
EntidadHoja ER → EntityRectángulo
RelaciónHoja ER → RelationshipRombo
AtributoHoja ER → AttributeÓvalo
Línea que uneHerramienta de línea o arrastre desde el bordeLínea
CardinalidadHerramienta Texto (tecla T)1:N, N:M
El orden de dibujo que funciona
  1. Colocá las entidades (rectángulos) y escribí su nombre en MAYÚSCULAS.
  2. Agregá los atributos (óvalos) alrededor de cada entidad y unilos con una línea.
  3. Subrayá el atributo clave: doble clic en el texto y Ctrl + U.
  4. Colocá el rombo de la relación entre las entidades que une.
  5. Escribí la cardinalidad con la herramienta Texto, al lado de cada línea.
  6. Si la relación es N:M, agregá la entidad intermedia como un rectángulo más.
Los casos especiales
AtributoCómo se dibuja en Dia
ClaveÓvalo con el nombre subrayado (Ctrl + U).
MultivaluadoDoble óvalo: dos óvalos superpuestos.
DerivadoÓvalo con línea punteada (Formato → Línea → punteada).
Prolijidad: alineá las entidades en una misma columna, dejá aire entre los óvalos y usá el mismo tamaño de letra en todo el dibujo. Un MER ordenado se corrige mucho más rápido.
Error clásico: escribir la cardinalidad dentro del rombo. La cardinalidad va sobre la línea, en cada extremo: 1 del lado de la entidad y N del lado de la relación.

✍️ Ejercicio: planificá el MER en la hoja ER

Para el caso de la tienda (CLIENTE, PRODUCTO y la compra con fecha y cantidad), escribí los pasos para dibujarlo en Dia: qué hoja elegís, qué figura usás para cada elemento, cómo marcás la clave, cómo ponés la cardinalidad y qué hacés con la entidad intermedia.

Ver la solución esperada
  • Hoja: ER, en el desplegable de la paleta.
  • Entidades: figura Entity (rectángulo) para CLIENTE y PRODUCTO.
  • Atributos: figura Attribute (óvalo), unidos con una línea.
  • Relación: figura Relationship (rombo) entre las entidades.
  • Clave: el atributo subrayado (Ctrl + U) dentro del óvalo.
  • Cardinalidad: herramienta Texto (T) y escribir 1:N o N:M sobre la línea.
  • Intermedia: un rectángulo más (COMPRA), porque la relación es N:M.

3 La hoja Database: dibujar el DER

Para el DER se cambia a la hoja Database. Ahí están las figuras Table (tabla con columnas) y Reference (la línea que une una FK con su PK). Es la representación que después se convierte en CREATE TABLE.

Qué querés dibujarHoja y figura en Dia
TablaHoja Database → Table
Columnas, tipos y PKDoble clic en la tabla: editor de columnas
Unión FK → PKHoja Database → Reference
Tabla intermediaOtra Table, con dos FK
Cómo se carga una tabla en Dia
  1. Colocá una figura Table en el lienzo.
  2. Hacé doble clic y abrí el editor de columnas.
  3. Escribí el nombre de cada columna, su tipo (INT, VARCHAR, DECIMAL, DATE) y tildá PRIMARY KEY donde corresponda.
  4. Repetí con cada tabla: clientes, productos y compras.
  5. Uní con Reference la FK de compras con la PK de clientes, y la otra FK con la PK de productos.
Cómo se ve la intermedia en la hoja Database compras
  id_compra       INT  PK
  cliente_dni     INT  FK → clientes.dni
  producto_codigo INT  FK → productos.codigo
  fecha           DATE
  cantidad        INT
La regla de la intermedia: la tabla compras no tiene un símbolo especial. La reconocés porque tiene una PK propia y dos FK, una hacia cada entidad de la relación N:M.
Dia no genera el script SQL solo: dibuja el DER, pero el CREATE TABLE se escribe aparte en MySQL. El diagrama es la guía; el script es el que crea la base de verdad.

4 Guardar, exportar y entregar

Guardar y exportar no son lo mismo. Guardar crea un archivo .dia que podés seguir editando. Exportar crea una imagen o un PDF para entregar o mostrar. Siempre se guarda primero y se exporta después.

AcciónMenúQué obtiene
GuardarArchivo → Guardar (Ctrl + S)Un archivo .dia editable
Guardar comoArchivo → Guardar comoUna copia con otro nombre
ExportarArchivo → ExportarPNG, SVG, PDF u otro formato de imagen
Abrir un trabajoArchivo → AbrirEl .dia con todas las capas
Nombres de archivo que no fallan
  • Minúsculas, sin espacios y sin ñ: mer_tienda_ana.dia.
  • Un archivo para el MER y otro para el DER.
  • Si entregás una imagen, exportá en PNG (se ve en cualquier lado) o PDF (no se deforma).
  • Antes de exportar, hacé zoom para ver todo el diagrama y comprobá que no quede nada cortado.
Atajos que ahorran tiempo
AtajoHace
Ctrl + SGuardar
Ctrl + ZDeshacer
Ctrl + DDuplicar la figura seleccionada
Ctrl + ruedaZoom
SuprBorrar la figura seleccionada
THerramienta Texto
Antes de cerrar: guardá el .dia, exportá el PDF y abrí el PDF para verlo. Si el PDF se ve bien, el trabajo está listo para entregar.
Error clásico: entregar solo la imagen y perder el .dia. Si hay que corregir algo, sin el archivo editable se empieza de nuevo.

✍️ Ejercicio: prepará la entrega

Pista: cuatro pasos
  1. Archivo → Guardar (Ctrl + S) con nombre en minúsculas.
  2. Archivo → Exportar a PNG o PDF.
  3. Abrir el archivo exportado para controlarlo.
  4. Guardar el .dia y la imagen en la misma carpeta.
